## <a name="1"></a>1. Google Gemini API кілтін алу (тегін!)

> 💡 Бұл кілт — ЖИ-ге қосылу үшін «құпия пароль». Біздің Gemini моделі **толық тегін**, күніне 250 жоспар жасауға жетеді.

### Қадамдар:

1. **aistudio.google.com** сайтын ашыңыз
2. Google аккаунтыңызбен **Sign in** (кіру). Аккаунт жоқ болса — жасаңыз ([accounts.google.com](https://accounts.google.com))
3. Терминалдағы шарттарды қабылдаңыз (Terms of Service)
4. Сол жақ менюден **«Get API key»** немесе **«API keys»** басыңыз
5. **«Create API key»** → **«Create API key in new project»** таңдаңыз
6. Шыққан кілтті көшіріп алыңыз — **`AIza...` деп басталады**

   ⚠️ **МАҢЫЗДЫ:**
   - Кілтті блокнотқа сақтап қойыңыз
   - **Несие картасы керек ЕМЕС** — толық тегін
   - Күніне **250 жоспар, минутына 10 жоспар** — бір мұғалімге артығымен жетеді

### 💡 Қазақстаннан кірмесе:

Кейбір жағдайда Қазақстаннан Google AI Studio ашылмауы мүмкін. Сол кезде:
- Аккаунт жасағанда **VPN** қосыңыз (мысалы: 1.1.1.1, ProtonVPN — тегін)
- Кілт жасап, көшіріп алған соң VPN-ді өшіруге болады
- API өздігінен Vercel сервері арқылы жұмыс істейді — VPN сізге қажет емес

## <a name="3"></a>3. Кодты GitHub-қа жүктеу

### Қадамдар:

1. **github.com** → жоғарғы оң жақтағы **«+»** → **New repository**
2. **Repository name:** `qmj-zhasaushy` (немесе кез келген ат)
3. **Public** немесе **Private** — қалауыңызша. **Public** ашық болады, бірақ API кілт сонда емес — қауіпсіз.
4. ✅ **Add a README file** деген құсбелгіні **алып тастаңыз** (бізде өзіміздікі бар)
5. **Create repository** басыңыз

### Файлдарды жүктеу:

6. Жаңа репозиторий ашылған соң → беттің ортасында **«uploading an existing file»** сілтемесін басыңыз
7. **`qmj-app.zip`** файлды компьютеріңізде архивтен шығарыңыз (extract / распаковать)
8. **Барлық файлдарды** drag & drop арқылы беттің ортасына тастаңыз:

   📁 Жүктелетін файлдар тізімі:
   ```
   ├── api/
   │   └── generate.js
   ├── src/
   │   ├── App.jsx
   │   ├── main.jsx
   │   └── index.css
   ├── .gitignore
   ├── index.html
   ├── package.json
   ├── README.md
   ├── vercel.json
   └── vite.config.js
   ```

   ⚠️ **`node_modules` папкасын жүктемеңіз** (егер болса)!

9. Беттің төменінде → **Commit changes** басыңыз. Өзгеріс сақталды.

## <a name="4"></a>4. Vercel-ге орнату

1. **vercel.com** сайтын ашыңыз
2. **Sign Up** → **«Continue with GitHub»** (GitHub аккаунтыңызбен кіру)
3. Кіргеннен кейін → **«Add New...»** → **«Project»**
4. **«Import Git Repository»** бөлімінде өзіңіздің `qmj-zhasaushy` репозиторийіңізді табыңыз → **Import** басыңыз
5. Жаңа бет ашылады:
   - **Framework Preset:** автоматты «Vite» деп көрсетеді ✅
   - **Root Directory:** `./` (өзгертпеңіз)
   - Build / Output параметрлері — автоматты ✅

6. ⛔ **АЛДЫМЕН API кілтін қосыңыз** (5-қадам), сосын барып **Deploy** басыңыз!

## <a name="5"></a>5. API кілтін Vercel-ге қосу

Бұл — **ЕҢ МАҢЫЗДЫ** қадам. Кілт қосылмаса — қосымша жұмыс істемейді.

### Деплой алдында:

5-қадамдағы беттің астында **«Environment Variables»** деген бөлімді жайыңыз:

1. **Name:** `GEMINI_API_KEY` ← ДӘЛ ОСЫЛАЙ, әріптерді өзгертпеңіз!
2. **Value:** `AIza...` (өзіңіздің Google кілтіңізді қойыңыз)
3. **Add** басыңыз
4. **Deploy** басыңыз 🚀

### Егер кілтті ұмытсаңыз:

1. Vercel жобасын ашыңыз → **Settings** → **Environment Variables**
2. Жоғарыдағыдай қосыңыз
3. **Deployments** → соңғы деплойды табыңыз → **«⋯»** → **Redeploy**

## <a name="6"></a>6. Телефонға белгіше ретінде қосу

### 📱 iPhone (Safari браузері):

1. **Safari** ашып, сілтемені жүктеңіз
2. Төменде **Share** (жоғары жебелі квадрат) белгісі — басыңыз
3. Тізімнен **«Add to Home Screen»** (Басты экранға қосу)
4. Атын өзгертіп **Add** басыңыз

### 📱 Android (Chrome браузері):

1. **Chrome** ашып, сілтемені жүктеңіз
2. Жоғарғы оң жақта **⋮** (үш нүкте)
3. **«Add to Home screen»**
4. **Add** басыңыз

Енді басты экранда **«ҚМЖ Жасаушы»** белгісі пайда болады. Оны бассаңыз — нағыз қосымша сияқты ашылады! 🎉

## <a name="7"></a>7. Қателер шықса не істеу керек?

| Қате | Шешімі |
|------|--------|
| `GEMINI_API_KEY не задан` | Vercel → Settings → Environment Variables → кілтті қостыңыз ба? Қосқан соң **Redeploy** жасаңыз. |
| `API 400` немесе `Invalid API key` | Кілт қате. AI Studio → жаңа кілт жасап, Vercel-ге салыңыз. |
| `API 429 — Resource exhausted` | Күндік шектеуге жеттіңіз (250 сұраныс). Ертең қайта пайдалана аласыз. Немесе минутына көп сұрағаныңыздан — 1-2 минут күтіңіз. |
| `User location is not supported` | Кілт жасағанда VPN арқылы жасаңыз (АҚШ серверінен). Vercel сервері кілтті қолданғанда VPN керек емес. |
| Қосымша ашылмайды | Vercel → Deployments → соңғы деплой жасыл «Ready» дейме? Болмаса логты қараңыз (Function Logs). |
| ЖИ суреттерді көрмейді | Сурет 10МБ-дан кіші болсын. Анық, оқуға болатын фото жүктеңіз. |
